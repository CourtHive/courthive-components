<h3>Key Patterns</h3>

<ul>
  <li>
    <strong>Framework-agnostic</strong> — All components render to vanilla DOM elements. No React, Vue, or Angular
    dependency.
  </li>
  <li>
    <strong>CSS custom properties</strong> — Theming via <code>--chc-*</code> CSS variables: one light and one dark
    palette per user, selected with <code>data-theme</code> and <code>data-palette</code> (see Theme &amp; Palettes).
  </li>
  <li>
    <strong>Factory integration</strong> — Tournament logic powered by{' '}
    <a href="https://courthive.github.io/competition-factory/" target="_blank">
      Competition Factory
    </a>{' '}
    for CODES (a superset of TODS) data modeling.
  </li>
  <li>
    <strong>Controller pattern</strong> — Complex features (topology builder, scheduling profile, availability grid) use
    a controller layer that wires store, domain logic, and UI panels together.
  </li>
</ul>
